# 剪贴板

“剪贴板”让 NVDA 用户可以更方便地查看和重复使用 Windows 剪贴板内容。你可以浏览剪贴板、保留历史、处理图片和复制的文件，还可以在不同电脑之间同步内容。

## 系统要求

- NVDA 2026.3 或更高版本，且可使用 x64（AMD64）版本或 Windows 11 上的 ARM64 版本。
- 天坦剪贴板还需要 .NET 8 或更高版本。

## 浏览剪贴板

你可以按行、导航单位或字符浏览剪贴板文本。导航单位默认使用 Windows 词边界。你也可以在 NVDA“设置”对话框的“剪贴板”类别中改为按 Unicode 标点符号拆分，并选择是否将每个标点字符作为单独的导航单位。默认还会根据大小写进一步拆分 `getWord` 这类连写单词；该选项对两种拆分方式都生效，也可以关闭。不单独导航标点时，连续的分隔标点及其后的空白会尽可能附加到前一段文本。如果剪贴板中是复制的文件，按行浏览命令会改为逐个浏览文件路径。声音提示可以帮助你判断是否到达边界，以及当前内容是否为非纯文本。

文本摘要会依次读出当前导航位置的行、字符列、总行数和字符统计；行列均从 1 开始，制表符计为一列。

文件综述不会朗读文件名，而会说明文件是复制、剪切还是创建链接、顶层项目数，并在后台统计完成后补充内容总大小以及递归包含的文件数和文件夹数。文件名和路径仍可通过按行命令逐项浏览。

在剪贴板中向上或向下翻页的命令没有默认手势。你可以在 NVDA“设置”对话框的“剪贴板”类别中调整每次翻页跳转的行数，并在“输入手势”对话框的“剪贴板”类别中为命令分配手势。

当前行和当前导航单位命令按一次朗读，按两次拼读，按三次读出字符描述。当前字符命令按两次读出字符描述，按三次读出字符的数值。

按 `NVDA+Alt+A` 可以把当前选中的文本追加到剪贴板。按 `NVDA+Shift+X` 可追加 NVDA 最后一次朗读的文本，按 ``NVDA+` `` 可临时粘贴该文本；临时粘贴会在之后尝试恢复原来的剪贴板。这些命令可在 NVDA“输入手势”对话框的“剪贴板”类别中重新分配。

按一次 `NVDA+C` 可朗读剪贴板摘要，按两次则在浏览模式下打开剪贴板内容。有 HTML 时会优先显示 HTML，否则会渲染 Markdown 和常见 LaTeX；可能执行脚本或加载外部资源的内容会被移除。若要按原文显示，可在 NVDA 设置的“剪贴板”面板中勾选“在浏览模式下原样显示剪贴板内容（不渲染）”。该手势会覆盖 NVDA 原有的剪贴板朗读命令。

## 剪贴板历史

复制的内容会自动进入历史，支持：

- 纯文本和带格式文本，包括 HTML 和 RTF。
- 图片，以及同时包含文本和图片的内容。
- 作为一个文件组保存的一份或多份复制文件。

按 `NVDA+E` 打开剪贴板管理器。在管理器中，你可以：

- 浏览和删除历史条目。
- 按 Enter 或选择“放入剪贴板”来恢复条目。此操作不会自动粘贴到应用中。
- 编辑文本，打开或保存文本文件，查找和替换文本（包括使用正则表达式），以及跳转到指定行。
- 创建自己的类别，把条目收藏或移动到类别中。
- 保存所选条目中的图片。

恢复带格式文本时会保留原有格式。在管理器中编辑这类条目的文字后，得到的是纯文本，原条目不会被修改。文件组只保存文件路径，并不会保存文件本身，因此源文件被移动或删除后，相应记录可能无法继续使用。

插件会自动删除较旧的历史条目，自建类别中的条目则会保留。图片存储空间有限，因此较旧且未收藏的图片可能会更早被清理。

你也可以不打开管理器，直接浏览已存条目。在 NVDA 的“输入手势”对话框中为“循环切换已存条目类别”命令分配手势，即可在剪贴板历史和用户类别之间循环切换；原有的上一条和下一条命令会在所选类别中移动，恢复命令会把选中的已存条目放入系统剪贴板。打开管理器时会定位到同一类别和条目。

## 图片

当剪贴板中包含图片时，综述会朗读精确尺寸和方向。如果图片全透明或为纯色，也会准确说明；如果至少 95% 的像素为黑色、白色或全透明，则会朗读相应像素占比。像素属性仅分析能够精确保留源像素的常见 PNG 和标准 24/32 位 DIB 数据；其他格式会省略像素属性，以免给出不准确的描述。插件不会推测图片内容。保存当前剪贴板图片的命令默认未分配手势；也可以在剪贴板管理器中保存所选条目的图片。按 `NVDA+PrintScreen` 可将当前导航对象复制为图片。

## 云同步

云功能并非必须使用，相关命令位于剪贴板管理器的“云”菜单中。

### OneDrive

OneDrive 可以在你的多个 NVDA 环境之间同步剪贴板历史和用户类别。请从“云 > OneDrive”登录 Microsoft 帐户。插件只能访问自己的 OneDrive 应用文件夹，无法访问你的其他文件。

同步是双向的，会在 NVDA 运行期间自动进行，也可以从“云”菜单手动开始。文本、格式和图片均可同步；复制的文件组只保留在创建它的电脑上。

删除已同步的条目或类别时，其他同步的 NVDA 环境也会执行删除。因此，OneDrive 同步不能替代备份。

### 天坦剪贴板

[天坦屏幕阅读器](https://www.tatans.cn)是一款面向中国市场的安卓端屏幕阅读器。NVDA Clipboard 集成了天坦云剪贴板 SDK，可在 Windows 端与天坦屏幕阅读器之间同步剪贴板文本。该功能仅限天坦 VIP 用户使用，默认禁用；启用后需要重启 NVDA，相关命令才会出现在“云”菜单中。

天坦剪贴板只同步文本，格式、图片和复制的文件不会上传。自动发送默认开启，可在“云”菜单中关闭；该菜单也提供手动发送和接收命令。

按 `NVDA+Alt+V` 会接收天坦文本并立即粘贴到当前应用。使用菜单手动接收时，文本只会留在剪贴板中，不会自动粘贴。

## 隐私

剪贴板历史保存在本机且不加密，其中可能包含敏感文本、图片和文件路径，仅受当前 Windows 帐户保护。

OneDrive 登录信息会针对当前 Windows 用户加密，但同步的剪贴板内容没有端到端加密。
