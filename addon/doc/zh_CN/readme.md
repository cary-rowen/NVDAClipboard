# 剪贴板

“剪贴板”让 NVDA 用户可以更方便地查看和重复使用 Windows 剪贴板内容。你可以浏览剪贴板、保留历史、处理图片和复制的文件，还可以在不同电脑之间同步内容。

保存在剪贴板历史和用户创建的类别中的内容，以下统称为“已存条目”。

## 系统要求

- NVDA 2026.3 或更高版本，且可使用 x64（AMD64）版本或 Windows 11 上的 ARM64 版本。
- 天坦剪贴板还需要 .NET 8 或更高版本。

## 浏览剪贴板

你可以按行、导航单位或字符浏览剪贴板文本。导航单位默认使用 Windows 词边界。你也可以在 NVDA“设置”对话框的“剪贴板”类别中改为按 Unicode 标点符号拆分，并选择是否将每个标点字符作为单独的导航单位。默认还会根据大小写进一步拆分 `getWord` 这类连写单词；该选项对两种拆分方式都生效，也可以关闭。不单独导航标点时，连续的分隔标点及其后的空白会尽可能附加到前一段文本。如果剪贴板中是复制的文件，按行浏览命令会改为逐个浏览文件路径。声音提示可以帮助你判断是否到达边界，以及当前内容是否为非纯文本。

文本摘要会依次读出当前导航位置的行、字符列、总行数和字符统计；行列均从 1 开始，制表符计为一列。

文件摘要不会读出文件名，而会说明文件是复制、剪切还是创建链接、顶层项目数，并在后台统计完成后补充内容总大小以及递归包含的文件数和文件夹数。文件名和路径仍可通过按行命令逐项浏览。

在剪贴板中向上或向下翻页的命令没有默认手势。你可以在 NVDA“设置”对话框的“剪贴板”类别中调整每次翻页跳转的行数，并在“按键与手势”对话框的“剪贴板”类别中为命令分配手势。

当前行和当前导航单位命令按一次读出内容，连按两次拼读，连按三次读出字符描述。当前字符命令按一次读出字符，连按两次读出字符描述，连按三次读出字符的数值。

使用读出剪贴板摘要和查看剪贴板内容命令，可以读出摘要或在浏览模式下打开内容。有 HTML 时会优先显示 HTML，否则会渲染 Markdown 和常见 LaTeX；可能执行脚本或加载外部资源的内容会被移除。若要按原文显示，可在 NVDA 设置的“剪贴板”面板中勾选“在浏览模式下原样显示剪贴板内容（不渲染）”。这会替代 NVDA 原有的读出剪贴板命令。

### 选择和粘贴文本

使用标记剪贴板选区开始点和标记剪贴板选区结束点命令标记范围，在两点之间向前或向后移动。选区包含两个端点所在的字符。NVDA 会读出所选文本；文本较长时读出字符数。

使用粘贴剪贴板选区或当前已存条目命令粘贴所选文本。没有完整选区时（包括只标记了开始点），该命令会粘贴当前已存条目。

选区保留期间，可以重复粘贴。重新标记开始点、浏览已存条目、切换类别或更换剪贴板内容，会清除原选区。

根据需要使用追加所选文本、追加最后朗读的文本和粘贴最后朗读的文本命令。这些命令可在 NVDA“按键与手势”对话框的“剪贴板”类别中重新分配。

## 剪贴板历史

复制的内容会自动进入历史，支持：

- 纯文本和带格式文本，包括 HTML 和 RTF。
- 图片，以及同时包含文本和图片的内容。
- 作为一个文件组保存的一份或多份复制文件。

打开剪贴板管理器。在管理器中，你可以：

- 浏览和删除历史条目。
- 选择“放入剪贴板”，将所选条目放入系统剪贴板。此操作不会自动粘贴到应用中。
- 编辑文本，打开或保存文本文件，查找和替换文本（包括使用正则表达式），以及跳转到指定行。
- 创建自己的类别，把条目收藏或移动到类别中。
- 保存所选条目中的图片。

将带格式文本放入剪贴板时会保留原有格式。在管理器中编辑这类条目的文字后，得到的是纯文本，原条目不会被修改。文件组只保存文件路径，并不会保存文件本身，因此源文件被移动或删除后，相应条目可能无法继续使用。

插件会自动删除较旧的历史条目，用户类别中的条目则会保留。图片存储空间有限，因此较旧且未收藏的图片可能会更早被清理。

### 浏览和粘贴已存条目

你也可以不打开管理器，直接浏览已存条目。使用循环切换已存条目类别命令，可在剪贴板历史和用户类别之间切换。上一条和下一条命令在所选类别中移动，默认手势见下表。打开管理器时会定位到同一类别和条目。

浏览到所需条目后，使用粘贴剪贴板选区或当前已存条目命令粘贴。粘贴后仍停留在当前条目，可再次粘贴。插件会尽可能保留原有格式，必要时使用纯文本。

需要将条目放入剪贴板而不粘贴时，使用“将当前已存条目放入系统剪贴板”命令。

## 图片

当剪贴板中包含图片时，摘要会读出精确尺寸和方向。如果图片全透明或为纯色，也会准确说明；如果至少 95% 的像素为黑色、白色或全透明，则会读出相应像素占比。像素属性仅分析能够精确保留源像素的常见 PNG 和标准 24/32 位 DIB 数据；其他格式会省略像素属性，以免给出不准确的描述。插件不会推测图片内容。保存当前剪贴板图片的命令默认未分配手势；也可以在剪贴板管理器中保存所选条目的图片。使用将当前导航对象复制为图片命令可复制当前导航对象。开启黑屏后也可以截图。如果系统不支持，插件会提示先关闭黑屏。

## 云同步

云功能并非必须使用，相关命令位于剪贴板管理器的“云”菜单中。

### OneDrive

OneDrive 可以在你的多个 NVDA 环境之间同步剪贴板历史和用户类别。请从“云 > OneDrive”登录 Microsoft 帐户。插件只能访问自己的 OneDrive 应用文件夹，无法访问你的其他文件。

同步是双向的，会在 NVDA 运行期间自动进行，也可以从“云”菜单手动开始。文本、格式和图片均可同步；复制的文件组只保留在创建它的电脑上。

删除已同步的条目或类别时，其他同步的 NVDA 环境也会执行删除。因此，OneDrive 同步不能替代备份。

### 天坦剪贴板

[天坦屏幕阅读器](https://www.tatans.cn)是一款面向中国市场的安卓端屏幕阅读器。NVDA Clipboard 集成了天坦云剪贴板 SDK，可在 Windows 端与天坦屏幕阅读器之间同步剪贴板文本。该功能仅限天坦 VIP 用户使用，默认禁用；启用后需要重启 NVDA，相关命令才会出现在“云”菜单中。

天坦剪贴板只同步文本，格式、图片和复制的文件不会上传。自动发送默认开启，可在“云”菜单中关闭；该菜单也提供手动发送和接收命令。

“从天坦云剪贴板接收并粘贴”命令会接收天坦文本并立即粘贴到当前应用，默认未分配手势，可在 NVDA“按键与手势”对话框中自行分配。使用菜单手动接收时，文本只会留在剪贴板中，不会自动粘贴。

## 隐私

剪贴板历史保存在本机且不加密，其中可能包含敏感文本、图片和文件路径，仅受当前 Windows 帐户保护。

OneDrive 登录信息会针对当前 Windows 用户加密，但同步的剪贴板内容没有端到端加密。
