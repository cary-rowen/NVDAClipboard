# 剪贴板

“剪贴板”让 NVDA 用户可以更方便地查看和重复使用 Windows 剪贴板内容。你可以浏览剪贴板、保留历史、处理图片和复制的文件，还可以在不同电脑之间同步内容。

## 系统要求

- NVDA 2026.3 或更高版本，且必须使用 x64（AMD64）架构版本。当前尚不支持原生 ARM64 NVDA。
- 天坦剪贴板还需要 .NET 8 或更高版本。

## [ ] 原生 ARM64 支持

插件目前随附的 `_sqlite3.pyd`、`sqlite3.dll` 和 `ClipDataCloud.SDK.dll` 均为 x64 版本。插件启动时必须导入 `_sqlite3.pyd`，因此原生 ARM64 NVDA 当前无法加载本插件。天坦 SDK 是可选依赖，但在提供兼容 SDK 之前，ARM64 环境也无法使用天坦云剪贴板功能。

正式声明支持原生 ARM64 前，需要完成：

- 提供与 NVDA 内置 Python 版本匹配的 ARM64 `_sqlite3.pyd` 和 `sqlite3.dll`。
- 提供 ARM64 `ClipDataCloud.SDK.dll`；如果没有兼容 SDK，则应在 ARM64 环境中禁用天坦云剪贴板功能。
- 让插件包根据当前 NVDA 架构选择对应二进制文件，或根据条件选择是否加载二进制文件。
- 在原生 ARM64 NVDA 中验证插件启动、SQLite 历史操作以及天坦云剪贴板的功能可用性。

## 浏览剪贴板

你可以按行、词或字符浏览剪贴板文本。如果剪贴板中是复制的文件，按行浏览命令会改为逐个浏览文件路径。声音提示可以帮助你判断是否到达边界，以及当前内容是否为非纯文本。

向后或向前移动 10 行的命令没有默认手势。你可以在 NVDA“输入手势”对话框的“剪贴板”类别中为其分配手势。

当前行和当前词命令按一次朗读，按两次拼读，按三次读出字符描述。当前字符命令按两次读出字符描述，按三次读出字符的数值。

按 `NVDA+Alt+A` 可以把当前选中的文本追加到剪贴板。按 `NVDA+Alt+X` 可追加 NVDA 最后一次朗读的文本，按 ``NVDA+` `` 可临时粘贴该文本；临时粘贴会在之后尝试恢复原来的剪贴板。这些命令可在 NVDA“输入手势”对话框的“剪贴板”类别中重新分配。

## 剪贴板历史

复制的内容会自动进入历史，支持：

- 纯文本和带格式文本，包括 HTML 和 RTF。
- 图片，以及同时包含文本和图片的内容。
- 作为一个文件组保存的一份或多份复制文件。

按 `NVDA+E` 打开剪贴板管理器。在管理器中，你可以：

- 浏览和删除历史条目。
- 按 Enter 或选择“放入剪贴板”来恢复条目。此操作不会自动粘贴到应用中。
- 编辑文本，打开或保存文本文件，查找和替换文本（包括使用正则表达式），以及跳转到指定行。
- 创建自己的类别，把条目收藏或移动到类别中。
- 保存所选条目中的图片。

恢复带格式文本时会保留原有格式。在管理器中编辑这类条目的文字后，得到的是纯文本，原条目不会被修改。文件组只保存文件路径，并不会保存文件本身，因此源文件被移动或删除后，相应记录可能无法继续使用。

插件会自动删除较旧的历史条目，自建类别中的条目则会保留。图片存储空间有限，因此较旧且未收藏的图片可能会更早被清理。

你也可以不打开管理器，直接用全局历史命令浏览最近的条目，再把选中的条目放回剪贴板。

## 图片

当剪贴板中包含图片时，插件可以朗读图片尺寸和颜色位深。按 `NVDA+Alt+PrintScreen` 保存当前剪贴板图片，也可以在剪贴板管理器中保存所选条目的图片。按 `NVDA+PrintScreen` 可将当前导航对象复制为图片。

## 云同步

云功能并非必须使用，相关命令位于剪贴板管理器的“云”菜单中。

### OneDrive

OneDrive 可以在你的多个 NVDA 环境之间同步剪贴板历史和用户类别。请从“云 > OneDrive”登录 Microsoft 帐户。插件只能访问自己的 OneDrive 应用文件夹，无法访问你的其他文件。

同步是双向的，会在 NVDA 运行期间自动进行，也可以从“云”菜单手动开始。文本、格式和图片均可同步；复制的文件组只保留在创建它的电脑上。

删除已同步的条目或类别时，其他同步的 NVDA 环境也会执行删除。因此，OneDrive 同步不能替代备份。

### 天坦剪贴板

天坦剪贴板可以在本机与天坦云剪贴板之间传送文本，格式、图片和复制的文件不会上传。自动发送默认开启，可在“云”菜单中关闭；该菜单也提供手动发送和接收命令。

按 `NVDA+Alt+V` 会接收天坦文本并立即粘贴到当前应用。使用菜单手动接收时，文本只会留在剪贴板中，不会自动粘贴。

## 隐私

剪贴板历史保存在本机且不加密，其中可能包含敏感文本、图片和文件路径，仅受当前 Windows 帐户保护。

OneDrive 登录信息会针对当前 Windows 用户加密，但同步的剪贴板内容没有端到端加密。
